# EnglishLab — итоговый проект

Одностраничный сайт-визитка онлайн-курса английского языка.

## Файлы
- `index.html` — структура страницы и семантическая разметка.
- `style.css` — дизайн, Flexbox/Grid и адаптивность.
- `script.js` — интерактивность JavaScript: выбор тарифа, мини-тест уровня, форма и мобильное меню.

## Как запустить
1. Откройте папку проекта в Visual Studio / Visual Studio Code.
2. Откройте `index.html` в браузере.
3. Нажмите «Выбрать тариф» и пройдите мини-тест.

## Требования задания
- `<header>`, `<nav>`, 4 `<section>`, `<footer>`.
- Адаптивная верстка через Grid/Flexbox и media queries.
- Рабочие элементы JavaScript.
- Чистая структура HTML/CSS/JS.

## GitHub
Создайте новый публичный репозиторий, например `englishlab-project`.
Загрузите в него все три основных файла: `index.html`, `style.css`, `script.js`.

Для публикации через GitHub Pages:
Settings → Pages → Deploy from a branch → Branch: `main` → Folder: `/ (root)` → Save.

После публикации GitHub даст ссылку вида:
https://ВАШ-ЛОГИН.github.io/englishlab-project/
